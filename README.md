# LD_Induction
HealthRecon Connect L&D Induction course (self-paced, no build step).
## Deploy
Upload this folder to the repo root, then enable GitHub Pages (main branch, root). `.nojekyll` is included.
## Edit content
`js/content-core.js` (title, roles, functions, cast, modules) · `js/content-foundation.js` (Part 1 screens) · `js/config.js` (storage key, pass mark, videos: none).
## Cache-busting
Bump `?v=N` on every CSS/JS tag in `index.html` after each update.
## Saving
Progress saves to this browser (localStorage key in `config.js`). Nothing is sent anywhere.
## Fonts
Proxima Nova is a licensed font; confirm HRC's licence covers web use.
## Content governance
Leadership development resource, not legal, compliance, clinical, HR-policy or contract advice. Scenarios are de-identified and illustrative. Framework credits: Kolb (1984), Shannon and Weaver (1949), Hall (1976), Minto (1987), Tuckman (1965), Covey (1989).
